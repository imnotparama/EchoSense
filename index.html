SCHEMATIC & PINOUT

EchoSense Hardware Architecture

⚡ Power Distribution

  • 5V (VBUS / USB) Rail: Dedicated to Coin Vibration Motor & Active Buzzer via 2N2222 transistor (prevents LDO brownouts).
  • 3.3V Rail: Powers ESP32-S3 core, INMP441 I2S microphone, SSD1306 OLED, and RGB LED.
  • Noise Filtering: 100 µF Electrolytic + 0.1 µF Ceramic capacitors on 3.3V rail right beside the INMP441 microphone.

🎙️ Audio & Classification (TinyML)

  • INMP441 I2S: SCK → GPIO5 | WS → GPIO4 | SD → GPIO6 | VDD → 3.3V | GND, L/R → GND
  • Sampling: 16 kHz 16-bit mono stream processed by ESP32-S3 DSP vector extensions (ESP-NN / TensorFlow Lite for Microcontrollers).
  • Sound Categories: Fire alarm (3.1 kHz pulse), Doorbell (chime), Baby cry (400-600 Hz harmonic), Car horn (400/500 Hz blast).

📳 Haptic & Visual Feedback

  • Vibration Motor: 10mm flat coin motor powered by 5V rail; driven by 2N2222 BJT (Base → 1kΩ → GPIO18); protected by 1N4148 fast flyback diode.
  • RGB Status LED: Common Cathode (Cathode → GND; Anodes R, G, B → 220Ω → GPIO15, 16, 17).
  • SSD1306 OLED (0.96"): I2C interface (SDA → GPIO21, SCL → GPIO22, VCC → 3.3V, GND → GND).
  • Developer Buzzer: 5V active piezo buzzer on GPIO14 for auditory debugging cues.

🤖 Real-Time Acoustic Detection (TinyML)

  • Microphone Stream: INMP441 captures 24-bit studio audio via I2S, fed directly to ESP32-S3 DMA buffer.
  • On-Device Classifier: 1D-CNN TinyML model runs locally in 34ms using Xtensa DSP vector instructions.
  • Acoustic Profiles: Fire alarm (3.1 kHz), Doorbell (chime), Baby cry (harmonic), and Vehicle horn (dual-tone).
  • Simulation Dock: Bottom triggers provide instant acoustic and tactile response profile verification.
